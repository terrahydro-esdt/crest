Quick Start
============

Prerequisites
-------------

If you don't have a CUDA-capable GPU, use:

.. code-block::

    conda env create -f environments/environment_cpu.yaml

If you do have a CUDA-capable GPU, use:

.. code-block::

    conda env create -f environments/environment.yaml

Installation
------------
Future instruction to install using pip, e.g.

.. code-block::

    pip install crest


Future instruction to clone from GitLab, e.g.


.. code-block::

    git clone https://gitlab.smce.nasa.gov/astg/terrahydro/development/crest

and

.. code-block::

    cd crest
    pip install -e .
