# CREST Tutorial

CREST is a framework for building and running Earth System Models.
It uses a *hierarchical graph* (**Model Graph (HTG)**) to define model
components (**Base Node**) and their connections, wrapped by a high-level
**Model** object for training and prediction. Data from various sources
(**Data Abstractions**) is efficiently loaded, processed into batches
(**Batching**), potentially matched across grids (**Data Matching**),
and predictions are saved (**Archiver**), all orchestrated by a
**Configuration** and a high-level **Digital Replica Engine** for workflow execution.
