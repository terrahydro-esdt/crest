=====================================================
CREST: Coupled Reusable Earth System Tensor-framework
=====================================================

The goal of ``CREST`` is to provided a framework with end-to-end capabilities that leverages existing tensor network
software stacks and facilitates the creation of large open-science open-source AI-based Earth Systems models that span
across organizations.


Objectives
----------
* Provide a custom AI-based python framework for coupling tensor network models.
* Enable end-to-end system capabilities from data management to scenario analysis.
* Provide a hierarchal graph paradigm for building coupled models and the ability to plug-in another CREST model easily. 
* Leverage the Python ecosystem to integrate training, inference, and analysis through an easy-to-use GUI driver.
* Provide a standard to facilitate coupling models built across  different organizations.
