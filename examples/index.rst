Examples
=========

All examples are based on Jupyter notebooks that are hosted on GitLab.
If you want to run the code yourself, you can find the notebooks in the `examples folder <https://gitlab.smce.nasa.gov/astg/terrahydro/production/crest/examples>`__ of the CREST GitLab repository.

| **HTG_overview**

Overview of the CREST Hierarchal Tensor Graph

| **HTG_algebra**

Basic HTG computations

| **batcher_demo**

A demo of the batcher package

| **data_loader_demo**

A demo of the data loader package

| **mnist_demo**

An end-to-end demo of CREST using the MNIST dataset

| **cifar_demo**

CIFAR demo (needs description)

| **climetlab_demo**

CLIMETLAB demo (needs description)

| **archiver_demo**

ARCHIVER demo (needs description)
